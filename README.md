# ReelTale

Serialized short video stories: watch creators' live-action and stop-motion series, or write an opening and let
Meta's models turn it into a branching, illustrated, narrated story.

Built for the Meta Global AI Developer Hackathon (Indie track). Published by Euragnos B.V.

| Path | What |
|---|---|
| `apps/mobile` | Expo app for iOS, Android and web |
| `apps/server` | Cloudflare Worker on reeltale.net: API, webhooks, AI workflows, web hosting |
| `packages/shared` | Schemas shared by app and Worker |
| `supabase` | Database migrations, seed data, SQL tests |
| `legal` | Legal document drafts and the publishing script |
| `docs` | Handoff, decisions, changelog, hackathon write-up |

Setup notes for developers are in `docs/HANDOFF.md`.
